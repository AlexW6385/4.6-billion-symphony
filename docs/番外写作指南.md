# 番外写作指南

番外是挂在展览馆各地点旁的小故事，**不是原文**（界面会自动标注，正文不要提“番外”“展览馆”）。

## 用户的要求（按时间顺序，越后越重要）
1. 随意轻松有趣，不要刻意想表现什么，主题可以随机，甚至有点莫名其妙。
2. 不要太有逻辑太完满，不要引导到某个方向或固定的情绪；完全开放，有点不在乎，肆意创造和游玩。
3. 像外星人观察人类社会那样——大胆乱说，新奇的视角。
4. **不是机械的、假装客观的记录，而是像孩子一样调皮，用自己的眼光去看。** 参考原作里琳给漂泊号上的虚民"实现愿望"那一段——**很好笑的曲解**。

## 参考的味道
原作里有一段：琳替一群虚民“实现愿望”，每个愿望都被它按字面意思照办——想回家，就被送回出生的那个房间；想“想一想”，就问它“想一想”是不是就是愿望；一口气许了好几个，就挑两个实现，剩下的当没听见。琳自己的心里话轻飘飘的，觉得对方贪心，又觉得自己的通缉令写得太随便、赏金太低。（这里只是概括，不要去引原句。）

要学的是：
- **字面理解、按自己的逻辑曲解**别人的话、规矩、习俗、行为，然后一本正经地照着做或下结论。
- 叙述者（多半是琳，也可以是别的生物）**好奇、调皮、有点坏、毫不在乎**，看什么都新鲜，用自己的分类和比喻去理解陌生的东西（像外星人看人类社会、像小孩看大人）。
- 语气轻快，带一点琳式的内心吐槽和口头习惯：“……呢”“……吧”“感觉挺有趣的”“这样应该也算……了吧”“可不会有那种事情呢”。偶尔用“……”停顿。但别每句都加，别堆砌。
- 结论说完就走，不解释，不总结，不感慨，不煽情，不升华。可以停在一个随手的细节上。
- 好笑来自视角和曲解本身，**不要**靠告示、清单、投诉信、开会投票、值日表这类结构梗，也不要"铺垫—抖包袱—点题"的套路。
- 题材随便：任何地点、任何生物的日常小事、风俗、误会，琳去试一试、学一学、"帮帮忙"，或者别的生物用它们的眼光看琳/看别人。

## 示例
（虚民城市·电梯）
- 虚民有一种叫“电梯”的小房间。大家走进去之后，会全部转过身对着门站好，一句话都不说。
- 琳看了几次，觉得这是一种对门的礼节：门一打开，它们就赶紧离开，好像生怕打扰了门一样。
- 间谍也进去试了一次，不过它面朝墙站着。旁边的虚民一直盯着它看，大概觉得它对墙更有礼貌吧。

（记录体）
- 阿布说，记录体专门记录那些被忽视的东西。
- 琳看了看记录体对着的那块石头，觉得这块石头从头到尾都挺被忽视的，那岂不是要整块都记下来？难怪它一直不动呢。
- 后来琳往石头旁边丢了一粒沙子，记录体的一个小孔马上亮了一下。看来沙子比石头更被忽视一点。

（钻孔鱼）
- 几千条钻孔鱼挤在一道石缝里，缝里比外面暖和那么零点几度。
- 琳觉得它们是在排队取暖，只不过排队的方法是所有鱼同时往里挤。这样一次就能让大家都排不上，挺有效率的呢。

## 规则
- 用词条信息（entry / entry_s / entry_d）里的名字和设定，别和设定明显打架；情节完全虚构，不要复述原作剧情，不要写原作台词。页面上不能出现原文，和原著连续 12 字相同就算违规——全部用自己的话写。
- 每篇 2–3 段，总长 80–200 字。标题 t 2–8 字，可以俏皮一点。
- 中文标点，台词用“”或‘’，不要英文引号。内容健康，可以“有点坏”，但不要血腥细节。
- 彼此不要雷同，开头、视角、曲解的方式都要多样。

## 格式
番外在 `src/74_sides.js` 的 `SIDES` 数组里，每项大致是 `{id, at, e, t, d:[段落…]}`：`id` 唯一，`at` 指向挂靠的词条或地点，`e` 是出现的时代，`t` 是标题，`d` 是段落数组。写完跑一次 `python3 tools/check_overlap.py`。
