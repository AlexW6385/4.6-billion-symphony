# 架构

整个展览馆是一个单页：`src/` 里的文件按 `scripts/order.txt` 的顺序拼起来，就是 `index.html`。除第一个和最后一个外都是 JS 片段，共处一个立即执行函数里，互相直接调用。Three.js r128 从 CDN 加载。

数据单独放在 `data/`，作为普通脚本加载：

| 文件 | 内容 |
|---|---|
| `wiki.js` `wiki3.js` `wiki4.js` | 词条（`window.WIKI`）：名字、分类、所在世界与坐标、时代、简介 `s`、正文 `d`、章节 `ch`、相关词条 `rel`、造型 `k`/`kp` |
| `chapters.js` | 章节索引：只有卷名、章序与章名 |
| `links.js` | 词条之间的连线 |

## src/ 各部分

| 文件 | 做什么 |
|---|---|
| `00_head.html` | 样式、页面骨架、开场 |
| `10_core.js` | 渲染器、相机、拾取、空间切换、公共工具 |
| `20_fx.js` | 粒子、光晕、柔光精灵 |
| `30_creatures.js` `32_anatomy.js` | 生物：按部件拼装、放样的光滑身体 |
| `40_planet.js` | 所有圆形世界共用的星球构造（地形、海、云、大气） |
| `41_rongqiu.js` | 绒球：大陆、地标、生物群、词条落点 |
| `42_towns.js` `43_wilds.js` `44_life.js` `43_canon.js` `48_land.js` `49_sky.js` | 绒球上的城镇、荒野、小生物、按原文校正的地标、地面小物、天空 |
| `45_kit.js` `46_ents.js` `47_new.js` | 每个词条的造型：部件库、词条到造型的映射表（`ENT`）、后加的造型 |
| `50_void.js` `51_dream.js` `52_voidlife.js` | 虚空：琳去过的世界、梦境岛、虚空里的日常（碎石带、巴士航道、彗星、裂缝）；词条造型 `makeShape` |
| `60_worlds.js` `61_under.js` `62_worlds2.js` `63_closeups.js` | 其他世界：虚民母球、尔什、地下世界等 |
| `70_ui.js` | 界面：悬停名字、词条卡片、时间轴、图书馆、搜索、分享 |
| `72_reader.js` | 章节：卡片里的章节链接、阅读器（读者自己的 txt 只存在本机浏览器） |
| `74_sides.js` | 番外（界面标注“不是原文”） |
| `76_audio.js` | 声音：每个世界自己的旋律 |
| `99_tail.html` | 收尾 |

## 词条造型

- 星球上：`entryModels` 和生物群（herd）。
- 虚空等非星球空间：`placeEntries` 里，`k` 不是 `'none'` 就交给 `makeShape` 的对应分支；`k:'none'` 走 `entryShape()`，查 `46_ents.js` 的 `ENT` 表。

## 调试接口

页面暴露 `window.__rq`（`enterSpace(id)`、`CUR`、`ren` 等），测试脚本靠它跳转和检查。
